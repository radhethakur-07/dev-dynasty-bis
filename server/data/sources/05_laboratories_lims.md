# BIS Laboratories / LIMS Sources

PRIMARY:
- BIS LIMS home:
  https://lims.bis.gov.in/
- BIS Recognized Laboratories:
  https://lims.bis.gov.in/home/labs/

What to ingest:
- Lab name
- Lab code
- Address
- State/district
- Validity date
- Testing scope ONLY where the official source explicitly shows it
- IS number(s) associated with scope when explicitly shown
- Current status where explicitly shown

IMPORTANT:
LIMS itself warns that displayed scope is the scope submitted by the laboratory and may be subject to BIS verification. Preserve this disclaimer in relevant chunks.
