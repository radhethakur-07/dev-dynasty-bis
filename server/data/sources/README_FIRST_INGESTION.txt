server/data/sources/

Files:
- standards.csv

- consumer_faqs.md

IMPORTANT:
These are an initial, small source-backed seed set, not a complete BIS knowledge base.
Some records intentionally point to the current official BIS record/page rather than reproducing protected standard text.

The project should preserve:
- source_url
- retrieval date
- document/source status
- whether a record is demo or source-backed

Do not label a record as "official" merely because a URL is present; maintain the provenance metadata generated by the ingestion pipeline.

Recommended next step:
Run the ingestion pipeline in the project after placing these files in server/data/sources/ and verify:
1. parsing
2. chunking
3. embedding
4. Supabase insertion
5. pgvector retrieval
6. source citation rendering

Before production use, refresh time-sensitive records against the current BIS source.
